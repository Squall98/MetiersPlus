# Changelog

## v2.1.16 (3.3.5a port)

First release of the WotLK **3.3.5a** port of Advanced Trade Skill Window 2 (upstream
v2.1.16) for Ebonhold. Compatibility fixes only; no feature changes.

- Full window works on 3.3.5a: recipe list, reagents, scroll, search, sorting (incl.
  the custom-sort Editor), task queue and the Reagents / Task / Create action buttons.
- Enchanting works through the standard TradeSkill window.
- All Vanilla→WotLK API incompatibilities resolved (events, Craft API, vararg `arg`,
  Button font/colour methods, dropdown/scrollframe signatures, renamed globals, etc.).

Credit for the addon itself goes to its original authors — see the README.
